SUPPORT & GUIDELINES

Host Help Center

How does event review work?

Every event submitted by a verified host is evaluated by the EventHub curation panel for safety, accurate venue details, and ticketing integrity (~24h turnaround).

When are ticket payouts disbursed?

Payouts are automatically initiated to your registered bank account within 48 hours following successful event completion.

Can I update event details after publishing?

Yes! Minor updates to artist lineups and venue directions can be edited directly without re-entering the curation queue.
